- 增加封面候选尝试，并在失败后重新查询该版本资料；保留模型与版本匹配边界。
- 修复图片查询的简略记录覆盖完整模型资料、类型和模型系的缓存问题。
- 新增“精简资料”：确认清单后，将未改动的旧Luma兼容资料移入软件恢复区，可撤销；当前仅支持同一磁盘。

Luma 1.2.1

Luma 1.2.0

- GIF、WebP、APNG 支持逐帧播放、暂停和循环。
- TIFF 支持多页浏览和原始像素，PageUp / PageDown 切换页或帧。
- 同文件切换帧时保留画面、缩放和旋转，减少动态效果时不自动播放。
- 动图复用单个压缩容器，关闭或换文件释放；不预载整段像素。
- 帧缓存受现有配额限制，移除缓存时同步清理帧描述。
- 修复邻居预热失败影响当前图片、原始像素模式切换未更新缩放的问题。
